# Student Grade Tracker

A professional **Java Console-Based Application** developed using **Core Java** to manage student records and generate grade reports. This project was created as part of the **CodeAlpha Internship Program**.

---

## 📌 Project Overview

The **Student Grade Tracker** allows users to add student details, store marks, and generate a summary report including:

- Total Students
- Average Marks
- Highest Marks
- Lowest Marks

It also includes **Exception Handling** and **Input Validation** to make the program more professional and user-friendly.

---

## 🚀 Features

✅ Add Student Records  
✅ Validate Student Name  
✅ Validate Marks Input (0 to 100)  
✅ Exception Handling  
✅ Show Summary Report  
✅ Calculate Average Marks  
✅ Find Highest Marks  
✅ Find Lowest Marks  
✅ Menu Driven Console Interface

- Java

- OOP Concepts
- ArrayList
